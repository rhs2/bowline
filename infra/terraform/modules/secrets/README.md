# secrets

Secrets Manager entries for the values that belong to the application rather than to a managed service.

| Secret                                  | Value                                                        | Injected as              |
|-----------------------------------------|--------------------------------------------------------------|--------------------------|
| `bowline/<env>/jwt-secret`              | 32 random bytes as 64 hex characters (`random_id`)           | `JWT_SECRET` (api)       |
| `bowline/<env>/internal-service-token`  | 48 random alphanumeric characters (`random_password`)        | `INTERNAL_SERVICE_TOKEN` (api, billing, analytics) |
| `bowline/<env>/app`                     | JSON: `JWT_SECRET`, `INTERNAL_SERVICE_TOKEN` and `extra_values` | not injected; operator reference and third-party credentials |

Database, Redis and SMTP credentials are written by the `database`, `cache` and `mail` modules respectively, next to the resources they belong to.

## Rotation

Both values are generated by Terraform, so rotation is a replace of the random resource followed by an apply:

```
terraform apply -replace=module.secrets.random_id.jwt_secret
terraform apply -replace=module.secrets.random_password.internal_service_token
```

The ECS task definitions reference the secret ARNs (not versions), so a new deployment (or a forced one, `aws ecs update-service --force-new-deployment`) picks up the new values. Rotating `JWT_SECRET` invalidates every access token; users are refreshed transparently by the web app within 15 minutes because refresh tokens live in the database, not in the JWT. The full procedure, including the order that keeps billing and analytics reachable while the internal token changes, is in `docs/RUNBOOK.md`.

Do not edit the values in the console: Terraform owns them and the next apply would put the generated value back.

## Inputs

| Name                          | Type        | Default |
|-------------------------------|-------------|---------|
| `environment`                 | string      |         |
| `extra_values`                | map(string) | `{}`    |
| `secret_recovery_window_days` | number      | `7`     |
| `kms_key_id`                  | string      | `null`  |
| `tags`                        | map(string) | `{}`    |

## Outputs

`jwt_secret_arn`, `jwt_secret_name`, `internal_service_token_arn`, `internal_service_token_name`, `app_bundle_arn`, `app_bundle_name`, `all_secret_arns`.
